# anvil/

Package root for the Anvil framework: the skills, shared primitives, and
supporting scaffolding that ship into a consumer repo via
`scripts/install-anvil.sh`. This file is a signpost — each subdirectory
carries its own README with the real detail.

## Layout

| Directory | What it holds |
|---|---|
| [`skills/`](skills/README.md) | Per-artifact-type skills (`anvil:memo`, `anvil:deck`, `anvil:ip-uspto`, …), each `SKILL.md` + `commands/` + `rubric.md` + optional `templates/`, `assets/`, `examples/`, `tests/`, `lib/`. |
| [`lib/`](lib/README.md) | Shared framework primitives consumed by every skill: markdown snippets, the `_review.json` schema + critic aggregation, convergence/termination, citation resolution, rendering + preflight gates, figure theming, sidecar atomicity. |
| [`agents/`](agents/README.md) | Checked-in per-(skill, phase) subagent registrations (`anvil-<skill>-<phase>.md`), regenerated by `scripts/generate-anvil-agents.py`. |
| [`roles/`](roles/README.md) | Generic role definitions shared across skills (planned; none implemented yet). |
| [`templates/`](templates/README.md) | Scaffolds for new skills, rubrics, and consumer-facing starter themes/voice docs. |

See the repo root `README.md` for the consumer-facing install + usage guide,
`CLAUDE.md` for the full repository guide, and `ROADMAP.md` for design
philosophy and current state.
